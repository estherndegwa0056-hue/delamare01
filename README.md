# Delamare Farm Kenya — Website Package

A responsive, single-page website for the livestock, fodder, poultry and farm-appointment catalogue.

## Website section order

1. Dairy Cattle, Goats, Sheep & Livestock for Sale
2. Animal Feeds & Fodder — Quality Hay & Animal Feeds
3. Quality Fodder Solutions — Pasture & Fodder Grass Varieties
4. Delamare Farm Kenya Poultry — Day-Old & Growing Chicks
5. Farm Essentials — Feeds, Seeds & Fertilizer and related catalogue items
6. Visit Delamare Farm Kenya — Book a Farm Appointment

## Files

- `index.html` — website structure and page content
- `styles.css` — responsive layout and visual styling
- `script.js` — product catalogues, search/filtering, order and appointment interactions
- `assets/` — website images, icons and appointment guidebook
- `sitemap.xml` and `robots.txt` — search-engine discovery files (sitemap homepage URL must be set to the verified live domain before launch)
- `manifest.webmanifest` — web app metadata
- `GOOGLE-ADS-SEO-SETUP.md` — launch, SEO and advertising checklist

## Preview locally

1. Extract the ZIP while preserving the `assets` folder and all files.
2. Open `index.html` in a modern browser. For best results, serve the extracted folder through a local web server.
3. Upload the complete extracted folder to your web host; do not upload only `index.html`.

## Before publishing

- Confirm that you are authorized to use the Delamare Farm Kenya name, logos and branding, and that the domain is under your control.
- Confirm the official contact/WhatsApp number, product prices, availability, appointment fee and refund terms with the farm team.
- Confirm that all product photos accurately represent the products being offered.
- The live domain was not included with the supplied ZIP. Add the verified absolute canonical URL to `index.html`, set the absolute homepage URL in `sitemap.xml`, and add the sitemap URL to `robots.txt` after confirming the production domain. The sitemap cannot be made valid with a guessed domain.
- Configure Google Search Console and submit `/sitemap.xml` after deployment.
- Add Google Ads conversion tracking only after you have the correct Google tag / conversion ID and have tested the conversion action.

## Customer reviews

The customer feedback area is presented as a responsive card grid. The four testimonials already present in the supplied website have been retained; collect and publish additional customer-approved reviews before adding more attributed quotes. The WhatsApp review link is provided for customers to submit feedback. Do not publish invented names, locations, ratings or purchase claims as genuine reviews.

## Technical checks

The package is organized with all local assets retained. JavaScript syntax, HTML section order, local asset references and ZIP integrity were checked when this package was prepared. A live hosting, payment, WhatsApp delivery or Google Ads conversion test is not implied by these checks.


## Domain-specific SEO setup

Before launch, replace the relative/social preview URL metadata with the verified production URL, add `<link rel="canonical" href="https://YOUR-VERIFIED-DOMAIN/">`, and add that absolute homepage URL to `sitemap.xml`. Submit the sitemap in Google Search Console after deployment. The domain was not supplied, so no guessed domain has been embedded.
